# Acme Painting — Website Mockup

A design mockup for **Acme Painting**, a residential and commercial painting
company serving Austin, Texas and the surrounding Hill Country for 15 years.

This is a static, single-page site (HTML/CSS/vanilla JS, no build step) built
as a client mockup — reviews, contact details, and stats are sample content
for demonstration and should be replaced with real data before launch.

## Structure

- `index.html` — page content/markup
- `css/styles.css` — design tokens and styling
- `js/main.js` — mobile nav toggle, scroll reveal, sample form handling
- `Images/` — brand assets (logo)

## Local preview

No build step required — open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173
```

## Hosting

Published via GitHub Pages from the `main` branch root.
